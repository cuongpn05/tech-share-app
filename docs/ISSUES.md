## ISSUE #1: [Feature] Bộ khung Điều hướng 3 tầng: RootNavigator, AppDrawer, BottomTabs
Assignee: An  
Labels: `type::feature` · `priority::P0` · `sprint::0`

### Bộ khung Điều hướng 3 tầng Description
Thiết lập kiến trúc điều hướng 3 tầng chuẩn React Navigation 7 trên Expo SDK 57: `RootNavigator` (Native Stack) điều phối màn hình xác thực và app chính; `AppDrawer` (Drawer Navigator) cho phép mở menu ngăn kéo theo role `both`; `BottomTabNavigator` (Bottom Tabs) điều hướng 4 tab chính (Khám phá, Bản đồ, Đơn thuê, Hồ sơ).

### Objective
Cung cấp bộ khung chuyển trang mượt mà, phân quyền giao diện linh hoạt giữa vai trò Người thuê và Chủ máy, không bị giật lag khi chuyển tab.

### Scope of Work
- [ ] Cấu hình `src/navigation/RootNavigator.tsx` với Native Stack.
- [ ] Cấu hình `src/navigation/AppDrawer.tsx` tích hợp Custom Drawer Header hiển thị avatar và menu role `both`.
- [ ] Cấu hình `src/navigation/BottomTabNavigator.tsx` gắn icon vector tương ứng cho 4 tab.
- [ ] Cấu hình TypeScript typings cho các tham số điều hướng (`NavigationParamList`).

### Acceptance Criteria
- [ ] Chuyển đổi giữa 4 tab đáy mượt mà, giữ nguyên trạng thái scroll của từng tab.
- [ ] Vuốt mép trái mở Drawer Menu hiển thị đúng phân mục "Đơn thuê của tôi" và "Thiết bị của tôi".
- [ ] Không phát sinh cảnh báo lỗi TypeScript trên các hook `useNavigation()` và `useRoute()`.

- [ ] Xây dựng API Backend: `POST /api/auth/register` mã hóa mật khẩu với `bcryptjs.hash()`.

## ISSUE #3: [Feature] Đăng nhập (Login), JWT Token & AsyncStorage Session

Labels: `type::feature` · `priority::P0` · `sprint::1`

### Đăng nhập (Login), JWT Token & AsyncStorage Session Description

### Objective
Cung cấp cổng định danh tin cậy cho ứng dụng, duy trì trạng thái đăng nhập bền vững của người dùng qua các phiên mở app mà không bắt đăng nhập lại nhiều lần.

### Scope of Work
- [ ] Xây dựng màn hình `src/screens/auth/LoginScreen.tsx` với Formik + Yup.
- [ ] Xây dựng Redux slice `src/store/slices/authSlice.ts` quản lý `token`, `user`, `isAuthenticated`.
- [ ] Xây dựng API Backend: `POST /api/auth/login` kiểm tra mật khẩu bằng `bcryptjs.compare()` và ký token JWT.
- [ ] Viết hàm `loadStoredSession()` khởi tạo tự động trong `App.tsx` đọc token từ AsyncStorage.
- [ ] Cấu hình Axios Interceptor tự gắn header `Authorization: Bearer <token>` cho mọi request bảo vệ.

### Acceptance Criteria
- [ ] Đăng nhập đúng điều hướng thẳng vào màn hình Trang chủ (Home).
- [ ] Đăng nhập sai mật khẩu hiển thị thông báo: "Email hoặc mật khẩu không chính xác".
- [ ] Tắt hoàn toàn app và mở lại, ứng dụng tự động nhận diện đã đăng nhập và vào thẳng Home.

- [ ] Xây dựng dịch vụ client `src/services/adminService.ts`:

  - Cơ chế tự động kích hoạt `FALLBACK_ANALYTICS` khi không có kết nối internet hoặc backend bảo trì, đảm bảo giao diện dashboard không bị crash.

### Acceptance Criteria
- [ ] **Bảo mật & Phân quyền**: Chỉ tài khoản có `role === 'admin'` mới có thể mở màn hình Admin Dashboard và truy cập API `/api/admin/analytics`. Tài khoản thường truy cập sẽ bị chặn và thông báo lỗi không đủ quyền.
- [ ] **Trải nghiệm Sidebar**: Vuốt từ mép trái hoặc bấm nút Menu trên Header sẽ mở Admin Sidebar mượt mà; hiển thị đầy đủ thông tin Admin, avatar và danh sách các mục menu; bấm "Quay lại ứng dụng chính" đưa người dùng về trang khám phá ban đầu an toàn.
- [ ] **Hiển thị Bảng điều khiển**: Bảng điều khiển hiển thị đầy đủ, ngay ngắn 5 thẻ chỉ số KPI, thanh tỷ trọng 6 danh mục sản phẩm và khối tóm tắt việc cần làm; định dạng tiền tệ VND (`1.350.000 đ`) rõ ràng, dễ nhìn.
- [ ] **Làm mới dữ liệu**: Thao tác vuốt kéo xuống (Pull-to-refresh) kích hoạt xoay vòng loading và cập nhật số liệu mới nhất từ backend.
- [ ] **Chống lỗi ngoại tuyến (Offline Resilience)**: Khi ngắt kết nối mạng hoặc server không khả dụng, màn hình Dashboard tự động tải bộ dữ liệu dự phòng `FALLBACK_ANALYTICS`, giao diện hiển thị trọn vẹn và không phát sinh crash app.
